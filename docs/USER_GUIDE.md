# Руководство пользователя

## Назначение программы

Программа предназначена для контроля целостности файлов в выбранной папке. Ее можно использовать для учебной демонстрации принципов информационной безопасности: фиксации эталонного состояния файлов и последующего обнаружения несанкционированных изменений.

## Требования

- Python 3.10 или новее;
- библиотека `reportlab` для экспорта PDF.

Установка зависимости:

```powershell
pip install -r requirements.txt
```

На Windows можно выполнить установку двойным нажатием на файл `install_requirements.bat`.

## Создание базы хэшей

Команда:

```powershell
python main.py init <папка> <файл_базы.json>
```

Пример:

```powershell
python main.py init data/aerospace_demo hashes/aerospace_hashes.json
```

После выполнения появится JSON-файл с SHA-256 каждого найденного файла.

## Проверка целостности

Команда:

```powershell
python main.py check <папка> <файл_базы.json>
```

Пример с экспортом отчетов:

```powershell
python main.py check data/aerospace_demo hashes/aerospace_hashes.json --txt reports/report.txt --pdf reports/report.pdf
```

Программа выведет:

- количество файлов без изменений;
- новые файлы;
- измененные файлы;
- удаленные файлы.

## Просмотр текущих хэшей

```powershell
python main.py scan data/aerospace_demo
```

Эта команда не создает базу, а только показывает SHA-256 найденных файлов.

## Интерактивное меню

```powershell
python main.py menu
```

Меню подходит для показа работы программы без запоминания команд.

## Графический интерфейс

Для запуска окна программы:

```powershell
python main.py gui
```

На Windows можно открыть файл:

```powershell
run_gui.bat
```

Если библиотека для PDF-отчетов еще не установлена, `run_gui.bat` попробует установить ее автоматически. При запуске через `python main.py gui` программа также предложит установить `reportlab`, если пользователь включил PDF-отчет.

В окне доступны основные действия:

- выбор папки для контроля;
- выбор или создание файла базы хэшей;
- выбор путей для TXT и PDF отчетов;
- создание базы хэшей;
- проверка целостности;
- запуск демонстрации ORBIS-2.

Графический интерфейс сделан простым специально для учебной демонстрации. Вся основная логика остается в модулях программы, поэтому консольные команды и интерфейс используют один и тот же механизм проверки.

## Демонстрационный сценарий

```powershell
python main.py demo
```

Сценарий выполняет полный цикл:

1. копирует примерные файлы аэрокосмического аппарата ORBIS-2;
2. создает базу SHA-256;
3. изменяет файл телеметрии;
4. добавляет новый план восстановления;
5. удаляет файл калибровки полезной нагрузки;
6. формирует TXT и PDF отчеты.

Готовые результаты находятся в `examples/results/`.

## Возможные ошибки

Если программа пишет, что папка не найдена, проверьте путь к папке. Если PDF не создается, установите зависимость:

```powershell
pip install reportlab
```

TXT-отчет работает без дополнительных библиотек.
