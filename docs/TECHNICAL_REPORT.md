# Техническое описание проекта

## Тема

Программное средство контроля целостности файлов с использованием криптографических хэш-функций.

## Актуальность

Контроль целостности является одной из базовых задач информационной безопасности. Он позволяет обнаружить факт изменения файлов, в том числе после ошибки пользователя, сбоя, вредоносного воздействия или несанкционированного доступа. Такой подход особенно важен для конфигурационных файлов, журналов, телеметрии, программных модулей и служебных данных.

В учебном проекте используется пример с файлами аэрокосмического аппарата: телеметрией, настройками навигационного ПО, профилем полета и калибровочными данными полезной нагрузки.

## Цель работы

Разработать программу, которая фиксирует эталонное состояние файлов в папке и затем проверяет, не появились ли изменения.

## Задачи

- изучить принцип работы криптографических хэш-функций;
- реализовать вычисление SHA-256 для файлов;
- сохранить эталонные хэши в базе;
- выполнить повторную проверку;
- определить новые, измененные и удаленные файлы;
- сформировать отчет в TXT и PDF;
- добавить простой графический интерфейс для демонстрации работы;
- провести тестирование на примерных данных.

## Теоретические сведения

Хэш-функция преобразует входные данные произвольной длины в строку фиксированной длины. SHA-256 относится к семейству SHA-2 и формирует 256-битное значение, которое обычно записывается в виде 64 шестнадцатеричных символов.

Для контроля целостности важны следующие свойства:

- детерминированность: один и тот же файл всегда дает один и тот же хэш;
- лавинный эффект: даже небольшое изменение файла резко меняет хэш;
- сложность подбора другого файла с тем же значением хэша;
- фиксированная длина результата независимо от размера файла.

Программа не шифрует файлы и не восстанавливает удаленные данные. Она обнаруживает факт изменения, сравнивая текущее значение SHA-256 с сохраненным эталоном.

## Алгоритм работы

1. Пользователь выбирает папку для контроля.
2. Программа рекурсивно находит файлы.
3. Для каждого файла вычисляется SHA-256.
4. Результаты сохраняются в JSON-базу.
5. При повторной проверке программа заново вычисляет SHA-256.
6. Текущие данные сравниваются с базой.
7. Формируется список нарушений:
   - новые файлы;
   - измененные файлы;
   - удаленные файлы.
8. Пользователь получает отчет в консоли, TXT или PDF.

## Формат базы хэшей

База хранится в JSON. Для каждого файла сохраняются:

- относительный путь;
- SHA-256;
- размер файла;
- время последнего изменения.

Пример структуры:

```json
{
  "schema_version": 1,
  "algorithm": "SHA-256",
  "created_at": "2026-08-25T13:59:05+00:00",
  "controlled_folder": "C:\\path\\to\\folder",
  "files": [
    {
      "path": "telemetry/orbit_status.txt",
      "sha256": "ae9b54d0b099...",
      "size": 297,
      "modified_at": "2026-08-25T13:55:00+00:00"
    }
  ]
}
```

## Модули программы

- `hashing.py` - вычисление SHA-256;
- `scanner.py` - обход папки и сравнение записей;
- `database.py` - сохранение и загрузка JSON-базы;
- `reports.py` - экспорт TXT и PDF отчетов;
- `demo.py` - демонстрационный сценарий;
- `gui.py` - простой графический интерфейс на Tkinter;
- `cli.py` - консольный интерфейс и меню.

## Графический интерфейс

Для демонстрации разработан простой GUI на стандартной библиотеке Tkinter. Он позволяет выбрать папку, файл базы хэшей и файлы отчетов через системные диалоговые окна. В интерфейсе есть кнопки создания базы, проверки целостности, запуска демо-сценария и очистки журнала.

Использование Tkinter выбрано потому, что библиотека входит в стандартную поставку Python и не требует установки дополнительных GUI-фреймворков. Это упрощает запуск проекта на компьютере преподавателя.

PDF-экспорт использует библиотеку `reportlab`. Для удобства в проект добавлен файл `install_requirements.bat`, а запуск `run_gui.bat` автоматически проверяет наличие этой зависимости перед открытием интерфейса.

## Безопасность и ограничения

Программа обнаруживает изменение содержимого файла, но не определяет, кто именно внес изменение. Для защиты самой базы хэшей ее рекомендуется хранить отдельно от контролируемой папки или дополнительно защищать правами доступа.

Для больших каталогов время проверки зависит от количества и размера файлов. Хэширование выполняется блоками, поэтому программа не загружает крупные файлы целиком в оперативную память.

## Результаты демонстрации

В демо-сценарии используется папка `data/aerospace_demo`. После создания базы программа имитирует три события:

- изменение файла `telemetry/orbit_status.txt`;
- добавление файла `mission_docs/thermal_recovery_plan.txt`;
- удаление файла `payload/sensor_calibration.json`.

В результате отчет показывает 1 новый файл, 1 измененный файл и 1 удаленный файл.

## Вывод

Разработанное программное средство демонстрирует практическое применение криптографической хэш-функции SHA-256 для контроля целостности файлов. Проект относится к области информационной безопасности, имеет прикладную ценность и может быть расширен за счет графического интерфейса, планировщика проверок или отправки уведомлений.
