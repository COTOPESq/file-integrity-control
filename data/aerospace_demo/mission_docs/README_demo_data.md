# Описание демо-данных

Эта папка имитирует небольшой набор файлов аэрокосмического аппарата ORBIS-2:

- телеметрия орбиты;
- конфигурация навигационного ПО;
- профиль полета;
- калибровка полезной нагрузки.

Файлы нужны только для демонстрации контроля целостности. Они не содержат реальных сведений о действующих космических аппаратах.
