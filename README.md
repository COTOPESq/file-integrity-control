# Программное средство контроля целостности файлов

Учебный проект по информационной безопасности: программа на Python вычисляет SHA-256 для файлов выбранной папки, сохраняет базу хэшей и при повторной проверке показывает новые, измененные и удаленные файлы.

## Возможности

- выбор папки для контроля через консольные команды или интерактивное меню;
- рекурсивное вычисление SHA-256 для каждого файла;
- сохранение базы хэшей в JSON;
- повторная проверка папки по сохраненной базе;
- вывод новых, измененных и удаленных файлов;
- экспорт отчета в TXT и PDF;
- простой графический интерфейс для выбора папки, базы и отчетов;
- демо-сценарий на примерных данных аэрокосмического аппарата ORBIS-2;
- автоматические тесты.

## Быстрый запуск

```powershell
python main.py demo
```

Команда создаст рабочую копию демо-данных, сохранит базу хэшей, имитирует нарушения целостности и сформирует отчеты:

- `examples/results/aerospace_hashes.json`;
- `examples/results/integrity_report.txt`;
- `examples/results/integrity_report.pdf`.

Для запуска простого графического интерфейса:

```powershell
python main.py gui
```

На Windows можно также дважды нажать `run_gui.bat`. Этот файл сам проверяет наличие `reportlab` и при необходимости устанавливает зависимость для PDF-отчетов.

## Установка зависимостей

Для TXT-отчетов достаточно стандартной библиотеки Python. Для PDF-экспорта нужна библиотека `reportlab`.

```powershell
pip install -r requirements.txt
```

На Windows можно запустить:

```powershell
install_requirements.bat
```

## Основные команды

Создать базу хэшей:

```powershell
python main.py init data/aerospace_demo hashes/aerospace_hashes.json
```

Проверить папку и сохранить отчеты:

```powershell
python main.py check data/aerospace_demo hashes/aerospace_hashes.json --txt reports/report.txt --pdf reports/report.pdf
```

Показать SHA-256 всех файлов папки:

```powershell
python main.py scan data/aerospace_demo
```

Открыть интерактивное меню:

```powershell
python main.py menu
```

Открыть графический интерфейс:

```powershell
python main.py gui
```

Запустить тесты:

```powershell
python -m unittest discover -s tests -v
```

## Идея работы

При первичном запуске программа обходит выбранную папку и для каждого файла вычисляет SHA-256. Результаты сохраняются в базу. При повторной проверке программа заново вычисляет хэши и сравнивает их с базой:

- файла нет в базе, но он есть сейчас - новый файл;
- файл есть в базе и сейчас, но SHA-256 отличается - измененный файл;
- файл есть в базе, но отсутствует сейчас - удаленный файл.

SHA-256 используется как криптографическая хэш-функция: даже небольшое изменение содержимого файла приводит к другому хэшу.
